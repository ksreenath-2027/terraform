🚀 Terraform AWS EC2 Infrastructure

This project demonstrates how to provision AWS infrastructure using Terraform with a remote backend for state management.

📘 What is Terraform?

Terraform is an open-source Infrastructure as Code (IaC) tool that allows you to define, provision, and manage cloud resources using declarative configuration files.

Instead of manually creating resources in the AWS console, Terraform lets you:

Automate infrastructure setup
Version control your infrastructure
Reproduce environments easily
Manage changes safely using execution plans
